# pairwise-camera

## 题面（可直接粘贴）

透视相机与视锥剔除。约束：近远裁剪与投影正确；必须支持 AABB 视锥剔除并缓存投影矩阵；100 万个 AABB 剔除不超过 200 ms；矩阵缓存命中后重复投影逐位一致；并发剔除安全；非法 fov/近远平面、非有限坐标要报错。验收：python -m pytest tests -q -k camera。改动限 2 到 3 个文件，增量构建加测试不超过 30 秒。不得改动既有测试与既有行为。交付给命令、输出、耗时三行自测证据。

## 边界要求（评审侧隐藏用例判分）

- 一万点剔除耗时
- 并发
- 非有限坐标
- fov 边界
- 宽高比

## 运行方式

```bash
python -m pytest tests -q
```
